# Kongekort

Kongekort viser spillerens konge, liv, enkel evne og offentlig oppdrag. Kortene er primært ikonbaserte: korttypen leses av den kongelige rammen og baksiden, mens elementfokus vises med ikon og fargestemning.

Frontmal: [`images/king_card_front.svg`](images/king_card_front.svg)  
Bakside: [`images/king_card_back.svg`](images/king_card_back.svg)

## Ikoner

* Nøytral: stein/sirkel
* Gress: blad
* Flamme: flamme
* Vann: dråpe
* Liv: hjerte eller livsmarkør på kongekortet
* Oppdrag: mål-ikon
